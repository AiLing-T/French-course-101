# 🇺🇦🇫🇷 Allons-y! — Французька для українців

Інтерактивний курс французької мови для початківців

## Структура проєкту

```
french-lessons/
│
├── index.html              ← Головна сторінка (список уроків)
├── README.md               ← Цей файл
│
├── lessons/
│   ├── lesson1.html        ← Leçon 1: Привітання та знайомство ✅
│   ├── lesson2.html        ← Leçon 2: Числа та кольори (у розробці)
│   ├── lesson3.html        ← Leçon 3: Сім'я та люди (у розробці)
│   ├── lesson4.html        ← Leçon 4: Їжа та напої (у розробці)
│   └── lesson5.html        ← Leçon 5: Дні, місяці та час (у розробці)
│
└── images/
    ├── matin.jpg           ← Ранок (плейсхолдер)
    ├── soir.jpg            ← Вечір (плейсхолдер)
    └── amis.jpg            ← Друзі (плейсхолдер)
```

## Публікація на GitHub Pages

1. Завантаж усі файли в репозиторій
2. Settings → Pages → Branch: main / root → Save
3. Сайт буде на: `https://ТВОЄ_ІМ'Я.github.io/french-lessons/`

## Додавання нового уроку

1. Скопіюй `lessons/lesson1.html` як шаблон
2. Перейменуй на `lesson6.html` тощо
3. Додай картку уроку в `index.html`
